# 🛠️ Настройщик Discord-сервера для Minecraft-проекта

Комплект из двух скриптов, которые разворачивают структуру твоего Discord-сервера
в один запуск: роли, категории, каналы, права и кнопку верификации.

Сделано под **средний русский Minecraft-сервер** с тикетами, заявками на хелпера/ютубера/тиктокера,
реакция-ролями, уровнями, приветствиями и верификацией новичков.

## 📦 Что внутри

| Файл | Что делает |
|---|---|
| `setup_server.py` | Создаёт роли, категории и каналы с правами. Идемпотентный — можно запускать повторно. |
| `verify_bot.py` | Бот верификации: кнопка «Я человек», которая выдаёт роль `Verified`. Защита от рейд-ботов. |
| `requirements.txt` | Зависимости Python (discord.py + python-dotenv). |
| `.env.example` | Шаблон конфигурации. Скопируй в `.env` и впиши свои значения. |

## 🚀 Быстрый старт (5–10 минут)

### 1. Создай приложение и бота
1. Открой https://discord.com/developers/applications
2. **New Application** → назови как хочешь (например, `Server Setup`).
3. Слева вкладка **Bot** → **Reset Token** → **Copy**. Это твой `DISCORD_TOKEN`.
4. Ниже в разделе **Privileged Gateway Intents** включи:
   - ✅ **Server Members Intent**
   - ✅ **Message Content Intent**
5. Слева **OAuth2 → URL Generator**:
   - Scopes: `bot` и `applications.commands`
   - Bot Permissions: **Administrator** (для первичной настройки; потом уберёшь)
6. Скопируй получившуюся ссылку внизу и открой в браузере → выбери свой сервер → **Авторизовать**.

### 2. Установи зависимости
Нужен Python 3.10+ (проверь: `python3 --version`).

```bash
cd discord-setup
pip install -r requirements.txt
```

### 3. Заполни `.env`
```bash
cp .env.example .env
```
Открой `.env` в любом редакторе и впиши:
- `DISCORD_TOKEN` — токен бота
- `GUILD_ID` — ID твоего сервера
- `VERIFY_CHANNEL_ID` — (для verify_bot.py) ID канала с верификацией; его создаст `setup_server.py`, поэтому запусти сначала его.

### 4. Запусти настройку структуры
```bash
python setup_server.py
```
Скрипт создаст:
- **Роли:** Владелец, Администратор, Стафф, Хелпер, YouTube, TikTok, Разработчик, Бустер, Verified, Новичок, Новости, Обновления, Ивенты, Стримы.
- **Категории:** 📢 ИНФОРМАЦИЯ, 💬 ОБЩЕНИЕ, 🎮 ИГРА, 🛠️ ПОДДЕРЖКА, 🔊 ГОЛОСОВЫЕ КАНАЛЫ, 📺 МЕДИА.
- **Каналы:** правила, новости, обновления, анонсы, роли, общий, знакомства, мемы, оффтоп, команды, minecraft-чат, консоль, баг-репорты, предложения, магазин, тикет-панель, заявки, лог-тикетов, голосовые, скриншоты, видео, арт.

Базовая логика прав:
- `@everyone` видит всё, но **писать** могут только `Verified`.
- `Новичок` — роль без права писать (её снимает верификация).
- Каналы `консоль` и `лог-тикетов` видит только стафф.
- В `новости`, `обновления`, `анонсы` могут писать только управляющие.

### 5. Включи верификацию
1. Возьми ID канала, где хочешь видеть кнопку верификации (обычно канал `#правила` или отдельный канал `#верификация` в категории ИНФОРМАЦИЯ — создай его, если нужно).
2. Впиши его в `.env` как `VERIFY_CHANNEL_ID`.
3. Запусти:
```bash
python verify_bot.py
```
Бот отправит в канал сообщение с зелёной кнопкой. **Не закрывай окно**, пока бот должен работать.
Для продакшена лучше всего запустить бота на хостинге (см. ниже).

## 🤝 Подключение остальных ботов

Скрипты делают только «скелет». Дальше через веб-дашборды подключи:

### Carl-bot — реакция-роли, автомод, приветствия
- Сайт: https://carl.gg
- Пригласи бота, выбери сервер.
- **Reaction roles** → привяжи эмодзи к ролям `Новости`, `Обновления`, `Ивенты`, `Стримы` в канале `#роли`.
- **Welcome messages** → включи приветствие в `#общий` или отдельный канал `#приветствия` (создай через Discord).
- **Automod** → включи фильтры спама/инвайтов/плохих слов.

### Ticket Tool — тикеты
- Сайт: https://tickettool.xyz
- В дашборде создай **панель** для канала `#тикет-панель` с типами:
  - 🚨 Жалоба на игрока
  - 🐛 Баг-репорт
  - 🛒 Покупка / донат
  - ⚖️ Апелляция бана
  - 📝 Заявка на Хелпера
  - 📺 Заявка на YouTube
  - 🎵 Заявка на TikTok
- Support-ролями укажи `Стафф` и `Хелпер`.
- Логи транзакций направь в `#лог-тикетов`.
- Текст в `#заявки` с требованиями к кандидату (возраст, онлайн, контент) заполни сам.

### Arcane или Lurkr — уровни
- Arcane: https://arcanebot.xyz
- Lurkr: https://lurkr.gg
- В дашборде включи leveling, настрои награды-роли за уровни и no-XP каналы (например `#команды`).

### Wick / Dyno — антирейд
- Wick: https://wickbot.com  
- Dyno: https://dyno.gg
- Включи антирейд, антинюк, антиспам. Wick хорошо сочетается с верификацией от `verify_bot.py`.

### DiscordSRV — мост с Minecraft
- Скачай плагин: https://www.spigotmc.org/resources/discordsrv.18494/ или https://modrinth.com/plugin/discordsrv
- Положи jar в папку `plugins/` на Paper/Spigot-сервере и перезапусти.
- В `plugins/DiscordSRV/config.yml`:
  - вставь токен **отдельного** бота (не этого!),
  - в `Channels` укажи `global: "ID-канала-minecraft-чат"`,
  - в `DiscordConsoleChannelId` — ID канала `#консоль`.
- Полное руководство: https://docs.discordsrv.com/

## 🔐 После настройки: безопасность

1. Зайди в **Настройки сервера → Роли** и убери у бота `Server Setup` права администратора, если больше не планируешь запускать скрипты. Оставь только то, что нужно `verify_bot.py` (Manage Roles, View Channels, Send Messages).
2. У роли `Владелец` права администратора. Убедись, что она выше всех остальных ролей, и что она есть только у тебя.
3. Включи **2FA** на своём аккаунте и требование 2FA для действий модерации (Настройки сервера → Модерация → внизу).
4. В **Настройки → Модерация → Уровень проверки** поставь «Средний» или «Высокий».
5. Удали постоянное приглашение в сервер, которое светилось в чате, и создай новое с ограничением.

## ☁️ Где держать verify_bot.py постоянно

- На твоём ПК (бот работает, пока открыт терминал) — для теста.
- На хостинге: **Railway**, **Render**, **Fly.io**, **Oracle Cloud Free Tier**, любой VPS.
- Самый простой вариант — Raspberry Pi или старый ноут с `systemd`-сервисом.

Пример systemd-юнита (на Linux):
```ini
[Unit]
Description=Discord verify bot
After=network.target

[Service]
WorkingDirectory=/home/you/discord-setup
ExecStart=/usr/bin/python3 verify_bot.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

## 🆘 Частые проблемы

- **«Bot doesn't have permission to perform this action»** — роль бота должна стоять ВЫШЕ ролей, которые он создаёт/выдаёт. В настройках ролей перетащи роль бота наверх.
- **Команда `/setup` не появляется** — подожди до минуты после запуска (Discord кэширует слэш-команды) и проверь, что в OAuth-приглашении был scope `applications.commands`.
- **Кнопка верификации не работает** — проверь, что включены Server Members Intent и роль `Verified` существует.
- **Хочу ещё каналов/ролей** — отредактируй списки `ROLES`, `CATEGORIES` и `build_channels()` в `setup_server.py` и запусти скрипт снова. Он ничего не удаляет и не дублирует.
