# 🚀 Как запустить MineAurora Bot

Это **один бот**, который делает ВСЁ:
- 🎫 тикеты (7 типов обращений + анкеты на хелпера/ютубера/тиктокера),
- ✅ верификацию новичков (кнопка),
- 🎭 роли-уведомления по кнопкам (Новости, Обновления, Ивенты, Стримы),
- 👋 приветствия с аватаркой,
- 📈 уровни и XP за активность + автоматические роли-награды,
- 🛡️ базовый антиспам/антифлуд с мутом.

---

## ▶️ На своём ПК (для теста)

```bash
pip install -r requirements.txt
python mineaurora_bot.py
```

Бот сам отправит панели в каналы `#тикет-панель`, `#роли`, `#верификация`,
если их там ещё нет.

---

## ☁️ На Bothost.ru (24/7)

1. Зайди в панель Bothost.ru и создай приложение.
2. **Тип приложения:** Discord-бот.
3. **Язык/рантайм:** Python 3.11+ (выбери в настройках).
4. Загрузи файлы через файловый менеджер:
   - `mineaurora_bot.py`
   - `requirements.txt`
   - (`.env` НЕ загружай — токен вставь через переменные окружения)
5. **Стартовая команда** (Start Command):
   ```
   python mineaurora_bot.py
   ```
6. **Переменные окружения** (Environment Variables):
   - Ключ: `DISCORD_TOKEN`
   - Значение: **токен твоего бота**
7. Нажми **Запустить / Start**.

Через несколько секунд в логах появится:
```
🟣 MineAurora Bot запущен как MineAurora#xxxx
✅ Панель тикетов отправлена в #тикет-панель
✅ Панель ролей отправлена в #роли
✅ Панель верификации отправлена в #верификация
✅ Бот готов.
```

## 🛠️ Слэш-команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/panel` | админ | отправить/переотправить панель тикетов |
| `/roles_panel` | админ | панель ролей-уведомлений |
| `/verify_panel` | админ | панель верификации |
| `/welcome_test` | админ | проверить вид приветствия |
| `/xp [@user]` | все | показать уровень и опыт |
| `/level_rewards` | все | список наград за уровни |

---

## ⚙️ Что можно настроить

Открой `mineaurora_bot.py` в самом верху — блок `НАСТРОЙКИ`.
Там можно менять:
- имена каналов,
- награды за уровни (`LEVEL_ROLES`),
- сколько XP давать за сообщение,
- порог антиспама и длительность мута,
- и т. д.

После изменения — **перезапусти бота** в панели хостинга.

---

## ⚠️ Важно про права

Роль бота **MineAurora** должна стоять ВЫШЕ ролей, которые он выдаёт:
- Правый клик по серверу → Настройки сервера → Роли.
- Перетащи роль MineAurora наверх (под ролью владельца).

Иначе бот не сможет:
- выдавать Verified/Новичок,
- мьютить за спам,
- выдавать уровневые роли.

Также в Developer Portal на вкладке Bot должны быть включены:
- ✅ Server Members Intent
- ✅ Message Content Intent
